# Стартовый раздел документации Яндекс.Трекера

Прототип стартового раздела пользовательской документации для бизнес-аналитиков,
впервые работающих в трекере задач.

**Демонстрация:** https://kirovadasha11.github.io/ya_tr/

## Задача

Полная документация Трекера отвечает на любой вопрос — при условии, что вопрос уже
сформулирован. Стартовый раздел закрывает разрыв между «выдали доступ» и «поставил
первую задачу команде»: пять статей, 15–20 минут, дальше пользователь уходит в
основную справку.

## Что в прототипе

**Лендинг** — проблема пользователя, цель раздела, путь из пяти шагов
(получил доступ → нашёл очередь → создал задачу → оформил требования →
передал в работу), явные границы раздела.

**Раздел документации** — боковая навигация из пяти статей с пометкой состояния,
хлебные крошки, оглавление страницы с подсветкой текущего пункта, переходы к
соседним статьям, прямые ссылки вида `#create`.

**Полностью написана статья** «Создание задачи и основные приёмы работы с ней»:
введение, глоссарий, шесть шагов, раздел основных приёмов, справочный блок с
таблицей типичных ошибок. Остальные четыре статьи показаны структурой —
название, цель, ключевые подтемы.

## Технические решения

- Одна страница, без фреймворков и внешних зависимостей: HTML, CSS, JS.
- Иллюстрации — схематичные макеты интерфейса на CSS, а не снимки экрана.
  Каждый макет сопровождается нумерованными выносками и текстовым описанием,
  достаточным для понимания шага без просмотра изображения.
- Адаптивность: на узких экранах боковая навигация уходит в выдвижную панель.
- Данные в примерах вымышленные.

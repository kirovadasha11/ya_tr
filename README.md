# Быстрый старт в Я.Трекере для бизнес-аналитика

Прототип стартового раздела пользовательской документации для бизнес-аналитиков,
впервые работающих в трекере задач.

**Демонстрация:** https://kirovadasha11.github.io/ya_tr/

## Задача

Полная справка Я.Трекера отвечает на любой вопрос — при условии, что вопрос уже
сформулирован. Стартовый раздел закрывает разрыв между «выдали доступ» и
«поставил первую задачу команде»: четыре коротких статьи, около пятнадцати минут,
дальше пользователь уходит в основную справку.

## Состав

Слева — меню из двух уровней: страница «Анализ задачи и проектирование решения»
и раздел «Быстрый старт в Я.Трекере для бизнес-аналитика» с четырьмя статьями.

Главная — заголовок, плашка с обещанием результата и нумерованный список статей
со временем чтения и кратким описанием.

Полностью написана статья **«Создание задачи и основные приёмы работы с ней»**:
термины, шесть шагов от открытия формы до создания задачи, основные приёмы работы
с готовой задачей и таблица типичных ошибок. Остальные три статьи — заглушки
с названием, временем чтения и описанием.

## Оформление

Страница сделана по `STYLEGUIDE.md` тестового задания: белый лист, один шрифт
без засечек, один кегль основного текста `1.0625rem`, оранжевый акцент `#E8862A`,
колонка 720 px, сквозная колонка отступа 1,75 rem, разделители — волосяные линии.

## Технические решения

- Один самодостаточный HTML-файл: CSS и JS внутри, внешних загрузок нет.
- Весь текст лежит в разметке статически. Без JS страницы видны подряд и
  разделены линией, ссылки меню работают как обычные якоря. Скрипт делает одно:
  оставляет видимой одну страницу. Печать показывает всё содержимое.
- Иллюстрации — схематичные макеты интерфейса на CSS, а не снимки экрана.
  Каждый макет сопровождается нумерованными выносками и текстовым описанием,
  достаточным для понимания шага без просмотра изображения.
- Прямые ссылки вида `#create` работают.
- Данные в примерах вымышленные.

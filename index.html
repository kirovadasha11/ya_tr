Анализ задачи и проектирование решения

1Подход к выполнению задания

При проектировании стартового раздела рассматривались два принципа организации материала:

  • Функциональный подход: построение документации вокруг возможностей системы — очередей, задач, статусов и других функций
  • Сценарный подход: по рабочим сценариям пользователя — обучение через выполнение типовых рабочих задач

Для стартового раздела выбран комбинированный подход: в основу положен ключевой рабочий сценарий пользователя, а остальные статьи раскрывают функциональность, необходимую для его выполнения.
